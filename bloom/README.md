# 피어나다 Bloom

무엇이든 그어보세요 — 손끝의 선이 한 장의 수채화 꽃 그림으로 피어납니다.

어떤 선을 어떻게 그어도 아름다운 수채화가 되도록 만든 인터랙티브 아트 페이지입니다.
꽃잎과 잎은 벡터로 그리지 않고, 모두 수채 시뮬레이션에 "물과 물감을 붓질"하는 방식으로
그려지기 때문에 화면 전체가 한 장의 종이 위 그림처럼 번지고, 마르고, 겹칩니다.

```bash
cd bloom
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
```

## 제스처

| 그리는 방식 | 피어나는 것 |
| --- | --- |
| 길고 완만한 선 | 줄기. 선을 따라 잎과 곁가지가 자라고, 손을 뗀 끝과 가지 끝에 꽃·봉오리가 핌 |
| 닫힌 원 (시작·끝이 가깝고 크게 회전) | 원 크기만 한 큰 꽃 — 작약 / 장미 / 아네모네 중 하나, 안쪽 꽃잎부터 차례로 펼쳐짐 |
| 탭 / 짧은 점 | 작은 들꽃, 흩날리는 꽃잎, 열매 |
| 짧게 튕기는 선 | 잎 한두 장과 봉오리가 달린 작은 가지 |
| 빠르고 거친 지그재그 | 풀·잎 무더기 |

- 속도 → 붓 굵기 (빠를수록 가늘게)
- 펜 압력 또는 누르고 있던 시간 → 물감 농도와 꽃 크기
- 그은 방향 → 팔레트 안에서의 색 선택에 약하게 반영
- 멀티터치 지원, `Ctrl/⌘ + Z` 되돌리기

하단 막대: 계절 팔레트 4개 · 되돌리기 · 물로 씻기 · 저장 · 물소리(기본 꺼짐).
그림이 있는 상태에서 다른 계절을 고르면 종이를 물로 씻어낸 뒤 새 팔레트로 시작합니다
(되돌리기로 이전 그림과 팔레트를 복구할 수 있습니다).

### 수채 엔진

상태는 세 장의 RGBA16F 텍스처(물, 떠 있는 안료, 가라앉은 안료)를 ping-pong 하며
한 번의 MRT 패스로 갱신합니다. 안료는 색이 아니라 **흡광도**(−ln 반사율)로 저장하고
Beer–Lambert 로 합성하므로 겹칠수록 투명하게 깊어지는 감산 혼합이 되고(노랑+파랑 → 초록),
회색으로 탁해지지 않습니다.

- **확산**: 이웃 간 물·안료 플럭스를 반대칭식으로 계산해 질량이 보존됩니다. 마른 종이로는
  물이 문턱(종이 투수성 노이즈에 따라 불규칙)을 넘을 때만 번져서 가장자리가 자연스럽게 들쭉날쭉합니다.
- **건조와 가장자리 짙어짐**: 노출된 가장자리가 더 빨리 증발하고, 안료는 상대적으로 얇은 물막 쪽으로
  끌려가(커피 링 효과) 마른 경계에 몰립니다. 3~6초에 걸쳐 마릅니다.
- **그래뉼레이션**: 종이의 미세한 결(tooth)이 낮은 곳에 안료가 더 가라앉습니다.
- **글레이징**: 마른 안료는 거의 다시 녹지 않아 덧칠이 투명한 층으로 겹칩니다.
- **종이**: Worley 셀 + 섬유 노이즈로 만든 높이맵, 미색 `#F4EFE6`, 좌상단 조명, 약한 비네팅.
- **바람**: 아직 젖은 물감만 화면에서 살짝 흔들리고, 마른 꽃은 움직이지 않습니다.

### 성능

- 시뮬레이션 해상도는 표시 해상도(dpr 상한 2)의 1/2. 단, 1배율 화면에서는 반해상도가 CSS px 2칸당
  1셀이라 가는 줄기가 계단처럼 깨져서, 화소 예산(약 115만 셀) 안에서 CSS px 당 0.7셀 이하로는 내리지 않습니다.
- 업스케일은 4탭 B-spline 보간, 고정 스텝(120~180Hz)과 프레임당 스텝 상한.
- 모든 물이 마르고 개화가 끝나면 시뮬레이션과 렌더링을 멈춥니다.
- `prefers-reduced-motion`: 개화가 짧아지고 바람·장식 애니메이션이 꺼집니다.
