# 표지 보고 책 제목 맞히기

송년회용 퀴즈입니다. `index.html`을 크롬에서 더블클릭해서 엽니다. 서버나 설치가 필요 없습니다.

## 진행
| 키 | 동작 |
|---|---|
| `→` `Space` `PageDown` 화면 클릭 | 다음 힌트 → 정답 공개 → 다음 라운드 (리모컨 버튼 하나로 끝까지 진행) |
| `←` `PageUp` | 되돌리기 |
| `Enter` | 바로 정답 공개 |
| `N` / `P` | 다음 / 이전 라운드 |
| `T` | 타이머 일시정지·재개 (힌트마다 자동 시작) |
| `1`~`9` | (팀을 설정한 경우) 해당 팀에 지금 점수를 주고 정답 공개. 다시 누르면 취소 |
| `F` 전체화면 · `S` 설정 · `M` 소리 켜기/끄기 · `Esc` 두 번 | 처음 화면으로 |

## 설정 (`S`)
- 라운드별 정답, 보조 문구, 효과, 표지(파일 업로드 또는 `covers/1.jpg` 같은 경로), 제목 영역을 바꿀 수 있습니다.
- 제목 영역은 "제목 가리기" 효과의 가림막 위치이고, 다른 효과에서도 **제목 보호**(힌트 동안 제목 글자를 모자이크로 숨김)에 쓰입니다.
- 효과 목록에는 어울리는 힌트 단계(첫/중간/마지막)가 표시됩니다. **단계별 조합**을 고르면 힌트마다 다른 효과를 쓸 수 있고, 각 단계 목록 맨 위에 그 단계 추천 효과가 나옵니다.
- 설정과 업로드한 이미지는 이 브라우저에 저장됩니다. 다른 노트북으로 옮길 때는 "설정 내보내기/가져오기"를 쓰세요(업로드한 이미지도 포함됩니다).

## 폴더
- `cover-fx.js`: 효과 엔진 (독립 모듈)
- `covers/`: 표지 이미지 (알라딘 상품 이미지, 행사용)
- `share/`: 다른 페이지에 넣을 때 쓰는 전달 패키지 (`embed-example.html`, `README.md`)
