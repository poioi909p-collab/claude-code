# 북 퀴즈 통합 패키지

"표지 보고 책 제목 맞히기" 퀴즈를 내 웹페이지에 넣는 패키지입니다.
서버 프로그램이나 설치는 필요 없고, 이 폴더를 그대로 웹사이트에 올리면 됩니다.

## 폴더 구성
```
book-quiz/
├─ index.html          퀴즈 화면 (이 파일 하나가 퀴즈 전체)
├─ cover-fx.js         표지 효과 엔진
├─ covers/1~4.jpg      라운드별 표지
├─ fonts/              글꼴 (인터넷이 없어도 같은 디자인으로 보이게 함)
├─ embed-example.html  다른 페이지에 퀴즈를 넣은 예시
└─ README.md
```

## 내 페이지에 넣는 방법 (권장: iframe)
1. 이 폴더를 통째로 웹사이트에 올립니다. 예: `https://내사이트/book-quiz/`
2. 퀴즈를 보여줄 자리에 아래 코드를 붙입니다.

```html
<iframe src="/book-quiz/index.html" title="표지 보고 책 제목 맞히기"
        style="width:100%; max-width:560px; height:min(860px, 92vh); border:0; border-radius:20px; display:block; margin:0 auto;"
        loading="lazy" allow="fullscreen"></iframe>
```

- iframe 으로 넣으면 퀴즈 디자인과 내 사이트 디자인(CSS)이 서로 섞이지 않습니다.
- 퀴즈는 세로형입니다. 폭은 560px 정도, 높이는 700~860px 정도가 보기 좋습니다. 폭이 넓으면 가운데로 모입니다.
- `embed-example.html` 을 브라우저로 열면 실제로 넣은 모습을 볼 수 있습니다.

### iframe 을 쓸 수 없는 경우
- 퀴즈만 단독 페이지로 쓰려면 `index.html` 주소로 바로 연결하면 됩니다. 예: `<a href="/book-quiz/">북 퀴즈 하러 가기</a>`
- 노션·블로그처럼 iframe 주소만 넣는 곳은 `https://내사이트/book-quiz/index.html` 을 임베드 주소로 넣으면 됩니다.

## 첫 화면
처음 열면 스크롤 없이 한 화면에 다 보이는 소개 페이지가 나옵니다. 맨 위에서 **예시 표지(가상의 책 '밤의 서점')**로 조각 재배치가 어떻게 진행되는지 보여주고, 아래에 하는 법(표지를 일부러 바꿔 놨으니 보이는 부분만 보고 맞히기) · 문제마다 다른 방식 · 알아두기가 이어집니다. **시작하기**를 누르면 1라운드가 시작됩니다.

## 진행 방법 (보는 사람 기준)
- **다음** 버튼, 표지 탭, `→`·`Space` 키 중 무엇이든 누르면 힌트 → 정답 → 다음 책으로 넘어갑니다.
- 오른쪽 위 **고정 배치 / 랜덤 배치** 버튼: 기본은 라운드마다 정해 둔 고정 구조이고, 누르면 매번 무작위로 섞입니다.

| 라운드 | 정답 | 효과 | 힌트 |
|---|---|---|---|
| 01 | 무서운 게 딱! 좋아! | 조각 재배치 (16조각) | 4 |
| 02 | 해리 포터와 마법사의 돌 | 타일 뒤집기 (어드벤트 캘린더 문) | 4 |
| 03 | 지구 끝의 온실 | 김 서린 유리 | 3 |
| 04 | 물고기는 존재하지 않는다 | 손전등 (정해진 경로: 가장자리 → 물고기 떼 → 큰 물고기) | 3 |

## 바꾸고 싶을 때
`index.html` 아래쪽의 `const ROUNDS = [ ... ]` 에 라운드 4개가 순서대로 들어 있습니다.
- 정답·저자·출판 정보: `answer`, `author`, `meta`
- 라운드 색: `accent`
- 표지 이미지: `src` (covers 폴더의 파일)
- 제목을 가리는 영역: `regions` (표지 크기를 1로 본 비율 좌표)

## 확인한 환경
- 크롬 기준으로 만들고 크로미움에서 시험했습니다. 최신 엣지·웨일·사파리·휴대폰 브라우저에서도 동작하도록 만들었습니다.
- 파일을 더블클릭해서 열어도(file://) 동작합니다.

## 참고
- 글꼴(IBM Plex Sans KR, Instrument Serif)은 무료 오픈 라이선스(OFL)이고 라이선스 문서가 `fonts/` 에 들어 있습니다.
- 표지 이미지는 각 출판사의 저작물입니다. 외부에 공개되는 사이트라면 사용해도 되는지 먼저 확인해 주세요.
