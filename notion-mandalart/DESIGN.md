# 디자인 시스템 — 굴러가는 만다라트

노션 안에서 "고퀄"은 장식이 아니라 **일관성**이다. 아래 규칙을 모든 페이지에 같게 적용한다.

## 1. 페이지 골격 (모든 페이지 동일)
1. **커버**: 노션 기본 그라디언트(`notion.so/images/page-cover/gradients_*.png`, 외부 서비스 아님). 페이지 대표색과 톤을 맞춘다.
2. **아이콘**: 이모지 1개. 제목에는 이모지를 넣지 않는다(사이드바에서 아이콘과 겹침).
3. **빵부스러기 줄**: 회색 작은 글씨로 관련 페이지 3~6개 링크 (`홈 · 보드 · …`).
4. **안내 콜아웃 1개**: 대표색 `_bg`, 한두 문장, 첫 구절은 굵게.
5. **버튼 줄** (있으면) → **섹션** (`## 이모지 + 짧은 명사` · 대표색).
6. 맨 아래 **토글**: 설명·예외·팁. 본문은 짧게, 자세한 건 접어 둔다.

## 2. 색 = 역할
| 대표색 | 페이지 | 의미 |
|---|---|---|
| blue | 홈 · 비교 대시보드 | 지금 · 숫자 |
| purple | 만다라트 보드 · 모바일 보드 | 구조 |
| green | 기간 계획 · 습관 체크 | 진행 · 성장 |
| orange | 할 일 | 행동 |
| brown | 회고 | 돌아봄 |
| red | 작년 목표 해부 | 원인 |
| pink | 재시작 센터 | 회복 |
| yellow | 추천 라이브러리 · 루트 안내 | 아이디어 |
| gray | 가이드 · DB | 참고 |

세부목표 8칸의 **색상 라벨**은 레드 → 오렌지 → 옐로 → 그린 → 블루 → 퍼플 → 핑크 → 브라운(위치 1→9, 5 제외). 수식 `색`이 이 값을 노션 색으로 바꿔 보드·할 일·실행 기록의 세부목표 이름을 같은 색으로 칠한다 → **어느 화면에서든 색만 보고 어느 칸인지 안다.**

## 3. 기호 사전 (모든 수식·문서 공통)
| 기호 | 뜻 |
|---|---|
| ■□ | 10칸 진행 바 (■ 대표색 · □ 회색) + 굵은 % |
| 🟩 🟨 ⬜ | 최근 7일 주간 목표의 80%+ · 1회 이상 · 0회 (월 n회는 30일 기준) |
| 💤 | 오래 기록 없음 (빈도 비례: 주 1회 이상 14일 · 월 2회 23일 · 월 1회 46일) |
| ✅ 🔴 | 미션 완료 · 기한 지남 |
| ⏸️ 🎓 | 쉬는 칸 · 졸업한 칸 |
| 🏅 🔥 | 세부목표 100% · 80%+ (도장) |
| 🚀 👍 ⚠️ | 페이스: 앞섬 · 유지 · 뒤처짐 |
| 🔥 오늘 꼭 · 🙂 여유 · 🧘 · 😌 | 오늘의 행동 우선순위 |
| 🌱 / 💪 | 최소 행동 / 완전 실행 |
| 🧩 🏃 🌦 | 실패 원인: 설계 · 실행 · 환경 |
| ▲ ▼ | 작년 같은 시점 대비 |

이모지는 **상태**에만 쓰고 장식으로 남발하지 않는다.

## 4. 수식 출력 스타일
- 상태 배지: `style(텍스트, "b", 색)` — 초록=좋음, 파랑=중립, 빨강=경고, 회색=안내.
- 강조 배경은 도장(🏅 `yellow_background`)·방치 경고(`gray_background`)·가운데 칸(`blue_background`)에만.
- 미니 그리드: 3줄 · 칸 사이 공백 3칸 · 가운데는 `◆ 세부목표`(그 색) 또는 `🎯 핵심목표`(파랑 배경).
- 짧은 이름 6자 이내 → 격자가 덜 흔들린다.

## 5. 레이아웃
- **홈은 1열 우선**(모바일에서 그대로 위→아래). 컬럼은 '이번 주/이번 달'처럼 대등한 두 정보에만.
- 보드는 3×3 컬럼 블록 + 칸마다 갤러리 1개(행 높이 정렬 보장).
- 링크된 뷰는 **데이터베이스 제목 숨김**, 뷰 이름은 이모지 + 2~6자.
- 갤러리 카드: 미리보기 없음, 속성 줄바꿈, 크기는 홈 작게 / 보드 중간 / 모바일·비교 크게.
- 표 뷰는 첫 열 다음에 버튼·상태 기호를 둔다(가로 스크롤 없이 누를 수 있게).

## 6. 문장 톤
- 해요체, 짧게. 명령보다 제안. 실패를 탓하지 않는 말(“무너짐” 대신 “멈춤”, “재시작 = 복귀 횟수”).
- 숫자는 구체적으로(“15분”, “3분 재시작”).
