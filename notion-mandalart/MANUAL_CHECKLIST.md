# 수동 마무리 체크리스트

API·MCP로 만들 수 없거나 확인이 필요한 것들. 빌드 세션이 실제로 만든 것은 지우고, 남은 것만 사용자에게 넘긴다.
예상 소요: 버튼 25개 약 40분 · 뷰를 손으로 만들 경우 64개 약 2시간 · 나머지 20분.

## A. 버튼 (무료 플랜에서 되는 유일한 자동화)
전체 목록과 설정값: **`out/buttons_checklist.md`** (manifest 에서 자동 생성).

**페이지 버튼 블록 만드는 법** — 자리표시자 `🔧 버튼: …` 를 지우고 `/버튼` → 이름 입력 → **＋ 작업 추가**:
- `Add page to <DB>` → 속성 값 지정(아래 표의 설정값), 템플릿이 있으면 **템플릿** 선택, **페이지 열기** 켜기
- 날짜 값 `Today` = 날짜 선택 창에서 **오늘(Today)**
- `Open page` 작업이 없으면 버튼 대신 페이지 링크(@멘션)로 대체

**DB 버튼 속성 만드는 법** — 해당 DB 표 머리글 ＋ → 유형 **버튼** → 이름(아래) → 작업 설정:
- [ ] **실천항목 · ✅ 오늘 했음** — `Add page to 실행 기록` · 실천항목 = **이 페이지(This page)** · 날짜 = **오늘** · 제목: 가능하면 수식 `This page.실천항목` (안 되면 비움)
- [ ] **실천항목 · 🌱 최소만 했음** — 위와 같고 최소만 했음 = ✔
- [ ] **실천항목 · 🔄 다시 시작** — `Edit pages` → **이 페이지** · 재시작일 = 오늘 · 활성 상태 = 활성 · 재시작 횟수 = 사용자 지정 수식 `This page.재시작 횟수 + 1` (수식 값 미지원이면 이 항목은 빼고, 가이드에 "직접 +1" 안내가 이미 있음)
- [ ] **만다라트 · 🧱 9칸 만들기** — `Add page to 세부목표` 작업 9개. 각 작업: 만다라트 = 이 페이지, 위치 = 1…9, 구분 = (5만 중심, 나머지 세부목표), 제목 = "세부목표 1"…(5는 "핵심목표"), 색상 라벨 = 레드·오렌지·옐로·그린·(5 없음)·블루·퍼플·핑크·브라운
- [ ] **세부목표 · 🧩 8칸 만들기** — `Add page to 실천항목` 작업 8개: 세부목표 = 이 페이지, 위치 = 1…8, 유형 = 습관, 활성 상태 = 활성, 비용 = 0원, 제목 = "실천 1"…"실천 8"
- [ ] **추천 라이브러리 · ➕ 내 만다라트로** — `Add page to 실천항목`: 실천항목 = 수식 `This page.항목`, 최소 행동 = `This page.최소 행동`, 유형 = 습관(수식 지원 시 `This page.유형`), 비용 = 0원, 활성 상태 = 활성, **페이지 열기** 켜기 (세부목표·위치는 사용자가 고름)

## B. 뷰
MCP로 뷰를 만들지 못했다면 **`out/views_checklist.md`** 의 표대로. 특히 신경 쓸 것:
- [ ] **보드 9칸**: 3행 × 3열 컬럼 블록 안에 갤러리 9개(필터 `현재 = true AND 위치 = n`). 각 뷰: 카드 크기 중간 · 미리보기 없음 · **속성 줄바꿈 켜기** · 표시 속성 미니 그리드/진행 바/도장/방치 경고 · 뷰 이름과 데이터베이스 제목 숨기기(••• → 제목 숨기기)
- [ ] 갤러리 카드에서 **미니 그리드** 줄바꿈이 보이는지 확인(안 보이면 속성 ••• → 줄바꿈)
- [ ] **기간 계획 · 🌳 계층**: 기간 목표 DB ••• → **하위 항목(Sub-items)** 켜기 → 관계 = 상위 기간 목표 / 하위 기간 목표
- [ ] **타임라인**: 끝 날짜에 수식 `기간 끝`을 고를 수 없으면 ① 기간 목표 DB에 날짜 속성 `타임라인 끝`을 추가하고 ② 타임라인을 `기간 시작 → 타임라인 끝`으로, 가이드 Step 5에 "타임라인 끝은 기간 끝 값을 보고 입력" 한 줄 추가. (수식은 그대로 둔다)
- [ ] 할 일 **이번 주** 보드: 그룹 = `요일`(수식), 그룹 정렬 오름차순
- [ ] 그룹 기준이 수식(`세부목표 색`, `세부목표`, `주원인`, `상위`)인 뷰가 그룹이 안 되면 → 그룹 없이 정렬 `위치`로 대체
- [ ] 차트 뷰는 **비교 대시보드에 1개만**(선택). 다른 곳에 만들지 않기

## C. DB 템플릿
`templates/*.md` 의 본문으로 생성. 각 DB ••• → 템플릿 → ＋ 새 템플릿.
- [ ] 회고 DB: 주간 회고 · 월간 회고 · 분기·스프린트 회고 · 중간 점검 · 최종 회고 · 재설계 회고 (각각 유형 속성 미리 지정)
- [ ] 실천항목 DB: 기본 실천항목 → **기본값으로 설정**
- [ ] 만다라트 DB: 새 만다라트 → 기본값
- [ ] 세부목표 DB: 세부목표 → 기본값
- [ ] 지난 목표 분석 DB: 지난 목표 해부 → 기본값
- [ ] 템플릿 안 `[[TVIEW: …]]` → 링크된 뷰. 필터에 **`<이 템플릿 이름>`** (자기 자신)을 고르면 새 페이지마다 자동으로 그 페이지로 바뀜. 회고 템플릿의 "이번 주" 필터는 상대 날짜 `이번 주`

## D. 디자인 마감 (DESIGN.md 참고)
- [ ] 전체 너비: 홈·보드·기간·할 일·습관·비교·해부·재시작·라이브러리·DB
- [ ] 수식 숫자 표시(선택): `달성률`·`전체 달성률`·`시간 경과율`·`습관 유지율` 속성 편집 → 표시 방식 **막대(Bar)** 또는 **링(Ring)**, 나누기 100, 색 = 페이지 대표색
- [ ] 모든 링크된 뷰: 데이터베이스 제목 숨기기, 불필요한 속성 숨기기(뷰 표에 없는 속성)
- [ ] 사이드바 순서: 홈 → 보드 → 모바일 → 기간 → 할 일 → 습관 → 회고 → 비교 → 해부 → 재시작 → 라이브러리 → 가이드 → 데이터베이스
- [ ] 홈·보드 페이지 잠금(••• → 페이지 잠금)으로 레이아웃 실수 방지 (DB 입력은 그대로 가능)
- [ ] status 옵션이 API로 안 바뀌었다면: 만다라트.상태 = 준비/진행 중/완료/보관, 기간 목표.상태 = 예정/진행 중/달성/미달성/이월 (이름이 수식과 같아야 함)

## E. 검증 (요청서 산출물 5)
- [ ] 모든 DB에서 수식 열에 빨간 에러 표시 **0개** (각 DB 표를 열어 확인)
- [ ] 샘플: 홈 카드 페이스·D-day·작년 이맘때 비교가 값으로 보임
- [ ] 샘플: 보드 9칸이 모두 채워지고 🟩🟨⬜💤⏸️ 가 섞여 보임
- [ ] 샘플: 실천항목 하나에서 ✅ 오늘 했음 → 실행 기록 추가 → 최근 상태·연속 기록·오늘 할 차례(✅ 오늘 완료) 변경 확인 → 추가된 기록 삭제
- [ ] 🔄 다시 시작 → 재시작일 오늘, 그 칸 누적 횟수 0부터 다시
- [ ] ➕ 이번 주 목표 → 기간 끝 = 시작 + 6일
- [ ] **무료 플랜 계정**에 템플릿 복제 → 위 항목 반복, 차트 뷰 외에 잠긴 기능 없는지
- [ ] **노션 모바일 앱**: 모바일 보드 열기 · 오늘 체크에서 버튼 누르기 · 홈 1열 순서 확인
- [ ] 공유: 루트 페이지 → 공유 → **웹에 게시** + **템플릿으로 복제 허용**
