## 빌드하는 법 (A안: Notion MCP)
1. claude.ai → 설정 → **커넥터**(https://claude.ai/customize/connectors)에서 **Notion** 연결
2. **새 Claude Code 세션**을 이 저장소로 시작 (커넥터는 세션 시작 때 읽힘)
3. 이렇게 요청: *"브랜치 `ccr-1a2dde95-im06of` 의 `notion-mandalart/BUILD.md` 대로 노션에 만들어 줘"*
4. 남은 클릭 작업: `MANUAL_CHECKLIST.md`

## 추가 요청 4가지는 이렇게 구현했다
| 요청 | 구현 |
|---|---|
| **작년에 실패한 목표를 분석하는 회고 시스템** | DB9 `지난 목표 분석` + 🔍 작년 목표 해부 페이지 + 가이드 Step 0. 실패 원인 15개(다중 선택)를 수식이 **설계 / 실행 / 환경** 점수로 나눠 `주원인`·`원인 분포(■)`·`처방`(어느 가이드 단계로 갈지)을 자동 표시. "왜? 5번" 템플릿, 교훈 한 줄, If-Then 재발 방지 규칙, 다음 결정. `반영한 세부목표`/`반영할 만다라트`로 올해 칸에 연결하면 `✅ 반영됨`. |
| **목표를 월간·주간·오늘의 행동으로 자동 분해** | 실천항목 수식 체인: 빈도·주간/월간 목표 횟수 → `기간 목표 횟수`(남은 기간 전체) → `자동 분해` "📆 기간 78회 → 월 13회 → 주 3회 → 오늘 🔥" → `오늘 할 차례`(이번 주 남은 횟수 ≥ 남은 날 수면 🔥 오늘 꼭, 월 n회는 이번 달 기준) → 홈 **🔥 오늘의 행동**이 `오늘 순서`로 정렬. 수치형 세부목표·기간 목표는 "남은 120쪽 → 월 40 · 주 9.3 · 오늘 1.3쪽". 기간 목표는 상위 기간 목표(자기 참조)로 분기 → 월 → 주 계층 + 하위 항목 토글. |
| **계획을 못 지켰을 때 다시 시작하는 재설계 기능** | 🔄 재시작 센터 + 가이드 "무너졌을 때". 수식 `재설계 신호`가 💤(빈도에 비례한 공백: 주 1회 이상 14일 · 월 1회 46일)·📉(지금까지 목표의 40% 미만) 칸을 찾아냄 → 문장을 줄이고 `이전 버전`에 원문 보관 → **🔄 다시 시작** 버튼이 `재시작일`=오늘 → `기준 시작일`이 바뀌어 그 칸의 누적·달성률을 **오늘부터 새로** 계산(과거 실패가 계속 발목 잡지 않음). `활성 상태`(활성/쉬는 중/교체됨/졸업)로 칸 교체, 회고 유형 `재설계`의 `변경한 실천항목`으로 이력. |
| **이전 목표와 현재 달성률을 비교하는 대시보드** | 📊 비교 대시보드. 만다라트끼리 `이전 만다라트`(자기 참조) 연결 + 월간 회고의 `누적 달성률` 스냅샷 → `작년 이맘때 비교` 수식이 **같은 경과 월**끼리 "같은 시점(2개월 차) 14% → 지금 21% ▲7%p". `성적표`(달성률·습관 유지율·방치 칸·재시작·회고 수), 나란히 비교 표, 분야별 비교, 교훈 반영 현황. 시스템 밖의 작년 목표는 `기록된 달성률`만 넣어 가볍게 옮겨 올 수 있음. 차트는 선택 1개(무료 플랜 한도). |

## 설계 결정 메모
- **롤업 대신 수식**: 중심 행 제외·활성 칸만 평균·색 입히기가 필요해 `관계형.filter().map()` 수식으로 계산. 결과는 롤업과 같고 무료 플랜에서 동작.
- **순환 참조 방지**: 중심 카드의 진행 바는 만다라트 `전체 달성률`을 읽지만 `전체 달성률`은 세부목표 `달성률`만 읽는다(서로 다른 속성). 검증기가 의존 그래프로 확인.
- **날짜 안전장치**: 실행 기록 `일자`·`경과일`을 날짜만으로 정규화 → 버튼이 시간을 넣어도 하루 계산이 틀리지 않음. 요일은 2024-01-01(월) 기준 나머지 연산이라 로케일·`day()` 반환값 차이에 영향받지 않음.
- **분야 목록 통합**: 요청서의 DB2 분야 목록과 라이브러리 12분야가 달라 하나(12 + 기타)로 합침.
- **달성률 0~100 정수**: API로 수식 숫자 형식(%)을 지정할 수 없어 0~100으로 계산, 표시는 ■□ 바. 노션의 막대/링 표시는 선택 마감.
- **실천 64칸 전부 활성 X**: 샘플·가이드 모두 세부목표당 2~3개만 활성(나머지 ⏸️ 쉬는 중) — 처음부터 64칸을 돌리면 💤가 쏟아진다.
