## 3. 쓰는 법 (매일 1분)
1. **홈** 열기
2. 한 일은 **✅ 오늘 기록** 표 아래 **＋ 새로 만들기** → 실천항목 고르기 (날짜가 비면 오늘로)
3. 안 되는 날은 최소 행동만 하고 **최소만 했음** 체크
- 회고: 회고 표 **＋ 새로 만들기** → 유형 고르기 → 📋 템플릿 원본에서 질문 복사
- 목표·할 일 추가: 각 페이지 표의 **＋ 새로 만들기**

## 4. 노션 API 때문에 바꾼 점
- **버튼**: API로 만들 수 없어서 "＋ 새로 만들기" 안내와 홈 ✅ 오늘 기록 표로 대체. 버튼은 원하면 나중에 직접 추가(`MANUAL_CHECKLIST.md` A)
- **DB 템플릿**: API로 만들 수 없어서 복사용 페이지로 대체
- **필터용 칸**: 수식 결과로는 API 필터가 안 돼서 DB 5개에 숨김 텍스트 수식 칸 `필터용`을 추가. **지우거나 이름을 바꾸면 안 됨**
- **뷰 그룹**: 수식 칸으로 그룹이 안 돼서 관계형·날짜·다중선택 칸으로 묶음 (예: 실천항목 → 세부목표별)
- **타임라인**: 끝 날짜가 수식이라 시작일만 표시
- **라이브러리**: 실천 후보 768개 중 484개만 넣음. 나머지 284개는 `out/library.csv`로 CSV 병합 가능(선택)

## 5. 확인한 것 / 못 한 것
- 확인: 홈 "지금 만다라트"에 진행 중 1개만 표시, 🔥 오늘의 행동·🚨 재설계 신호가 값을 냄 → 필터에 쓰는 수식은 정상 계산
- 못 함: 표시용 수식 값(달성률·진행 바 등)은 API로 읽을 수 없어 눈으로 확인 필요. 무료 플랜 복제·모바일 앱 확인도 직접 필요 (`MANUAL_CHECKLIST.md` E)
- 시작 가이드 하위 페이지에는 "✅ 버튼 누르기" 문장이 남아 있음 → "＋ 새로 만들기로 한 줄 추가"로 읽으면 됨
