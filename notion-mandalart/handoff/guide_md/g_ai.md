## 1. 프롬프트 복사 → 대괄호 채우기 → 무료 AI에 붙여 넣기

```plain text

너는 목표 설계 코치야. 아래 정보로 만다라트(핵심목표 1, 세부목표 8, 실천항목 64)를 만들어 줘.

[내 정보]

- 핵심목표: [예: 6개월 안에 정보처리기사 합격]
- 기간: [6개월 / 1년]
- 나이대·상황: [예: 20대 후반 직장인, 야근 주 2회]
- 하루에 쓸 수 있는 시간: [예: 평일 1시간, 주말 3시간]
- 예산: 0원 (헬스장·유료 강의·유료 앱·구독 없이 가능한 행동만)
- 작년에 실패한 이유(있다면): [예: 계획이 너무 컸고 하루 빠지면 포기함]
- 꼭 넣고 싶은 것 / 빼고 싶은 것: [자유]

[규칙]

1. 세부목표 8개: 실력 칸 외에 몸·마음·생활·관계 같은 받쳐 주는 영역을 2칸 이상 포함.
2. 실천항목: "빈도 + 숫자 + 동사" 문장 (예: 주 3회 30분 걷기, 매일 기출 20문제 풀기, 1회: 시험 일정 확인하기).
3. 각 세부목표의 실천항목 8개 = 습관 5~6개 + 미션 1~2개 + 마음가짐 1개.
4. 모든 실천항목에 "최소 행동"(안 되는 날 1분 버전)을 붙여.
5. 작년 실패 이유가 반복되지 않게 크기를 작게.
6. 짧은 이름은 공백 포함 6자 이내.

[출력 형식] 설명 없이 CSV 코드블록 2개만. 첫 줄은 열 이름 그대로.

CSV 1 — 세부목표.csv

세부목표,위치,짧은 이름,분야,색상 라벨,구분

(위치는 1,2,3,4,6,7,8,9 — 5는 쓰지 말 것. 분야는 건강·운동/식습관/수면·생활/공부·자격증/외국어/일·커리어/이직·취업/돈·저축/관계·가족/마음·멘탈/독서/취미·창작/기타 중 하나. 색상 라벨은 레드/오렌지/옐로/그린/블루/퍼플/핑크/브라운을 순서대로 하나씩. 구분은 모두 "세부목표")

CSV 2 — 실천항목.csv

실천항목,세부목표,위치,짧은 이름,유형,빈도,주간 목표 횟수,월간 목표 횟수,최소 행동,비용,활성 상태

(세부목표는 CSV 1의 이름과 글자 하나까지 똑같이. 위치 1~8. 유형은 습관/미션/마음가짐. 빈도는 매일/주 n회/월 n회/1회. 주 n회면 주간 목표 횟수에 n, 월 n회면 월간 목표 횟수에 n. 비용은 모두 0원. 활성 상태는 세부목표마다 위치 1~3과 마음가짐만 "활성", 나머지 "쉬는 중")

```

## 2. CSV 파일로 저장

- [ ] AI 답의 코드블록을 각각 복사 → 메모장에 붙여 넣고 `세부목표.csv` · `실천항목.csv` 로 저장 (인코딩 **UTF-8**)
- [ ] 엑셀로 열어 확인만 하고, 저장은 메모장으로 (엑셀 저장 시 한글이 깨질 수 있어요)

## 3. 노션에 병합 (데스크톱 앱 또는 웹)

- [ ] 먼저 만다라트 행을 만들고 상태 = 진행 중 (<mention url="https://app.notion.com/p/42156dd3dc5881d28259d6213878573b" />)
- [ ] <mention url="https://app.notion.com/p/42156dd3dc58819a85eee21c9e1b4bf6" /> → **세부목표** DB 열기 → 오른쪽 위 **•••** → **CSV로 병합(Merge with CSV)** → `세부목표.csv`
- [ ] 같은 방법으로 **실천항목** DB에 `실천항목.csv` 병합
- [ ] 세부목표 DB에서 방금 들어온 8행 + 가운데 행(위치 5, 구분 = 중심, 이름 = 핵심목표)을 만들고, 9행 모두 **만다라트** 칸에 내 만다라트 연결
- 9행을 Shift로 한꺼번에 선택 → 만다라트 칸 클릭 → 한 번에 연결돼요

## 4. 세부목표 연결이 비어 있으면

CSV의 "세부목표" 열이 관계형으로 자동 연결되지 않을 때가 있어요.

- [ ] 실천항목 입력 표에서 **세부목표 칸이 빈 행**만 보이게 필터
- [ ] 같은 세부목표 8행을 Shift로 선택 → 세부목표 칸에서 해당 세부목표 고르기 → 8개 동시에 연결
- [ ] 8번 반복하면 끝 → <mention url="https://app.notion.com/p/42156dd3dc588109b7ecf3522240f900" /> 에 9×9가 그려져요
