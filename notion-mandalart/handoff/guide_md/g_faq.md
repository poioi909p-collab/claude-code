📥 템플릿을 내 워크스페이스로 복제하려면?

템플릿 링크를 열고 오른쪽 위 **복제(Duplicate)** → 내 워크스페이스 선택. 복제 후 사이드바에 🎯 굴러가는 만다라트가 생겨요. 샘플 데이터는 이 페이지 맨 아래 '샘플 지우기'를 보세요.
</toggle>

<toggle>
🆓 무료 플랜으로 충분한가요?

네. 이 템플릿은 무료 플랜에서 되는 것만 써요: 관계형 · 수식 · 버튼 · DB 템플릿 · 링크된 뷰. **DB 자동화**(조건 트리거)와 **Notion AI**는 쓰지 않아요. 차트 뷰는 무료 플랜에서 1개만 보이기 때문에 진행률은 전부 수식 바(■□)와 이모지로 표시했고, 차트는 비교 대시보드에 선택 사항으로만 있어요.
</toggle>

<toggle>
🔗 관계형이 뭐예요?

두 표를 잇는 칸이에요. 실천항목의 '세부목표' 칸에 세부목표를 고르면, 그 세부목표 카드의 달성률·격자에 자동으로 들어가요. 반대편에도 자동으로 연결이 보여요(양방향).
</toggle>

<toggle>
🔘 버튼이 뭐예요?

누르면 정해진 일을 대신 해 주는 블록·칸이에요. ✅ 오늘 했음 = "실행 기록에 오늘 날짜로 한 줄 추가", ➕ 이번 주 목표 = "단위·시작일이 채워진 기간 목표 만들기". 무료 플랜에서 쓸 수 있는 유일한 자동화예요.
</toggle>

<toggle>
📱 폰에서는 어떻게 써요?

노션 앱에서 <mention url="https://app.notion.com/p/42156dd3dc58817e86d3ed493a6f64a1" /> 을 열고 ••• → **즐겨찾기 추가**. 9×9 보드는 폰에서 작게 보이니 모바일 보드에서 한 칸씩 보고, '오늘 체크' 목록에서 ✅를 누르세요. 버튼 칸은 표를 옆으로 밀면 보여요.
</toggle>

<toggle>
📅 날짜·D-day가 이상해요

- 노션 **설정 → 언어와 지역 → 시간대**가 한국(서울)인지 확인하세요.
- 만다라트 **시작일**이 비어 있으면 종료일·D-day·페이스가 안 나와요.
- 실행 기록 날짜에 시간이 들어가 있어도 날짜 기준으로 계산되니 괜찮아요.
- 수식 값은 페이지를 다시 열면 오늘 기준으로 새로 계산돼요.
</toggle>

<toggle>
🧩 보드에 칸이 ⬚ ─ 로 보여요

그 위치에 실천항목이 없거나 **위치** 숫자가 비어 있어요. 실천항목 입력 표에서 위치(1~8)를 채우세요. 세부목표 카드 자체가 안 보이면 세부목표의 위치(1~9)와 만다라트 연결, 그리고 만다라트 **상태 = 진행 중**을 확인하세요.
</toggle>

<toggle>
🗂️ 만다라트를 여러 개 쓰고 싶어요

만다라트 DB에 행을 더 만들면 돼요. 홈·보드에는 **상태 = 진행 중**인 것만 보여요. 동시에 2개를 진행하면 보드에 같은 위치 카드가 겹치니, 하나는 '준비'로 두는 걸 추천해요.
</toggle>

<toggle>
✏️ 속성 이름을 바꿔도 되나요?

바꾸면 수식이 깨질 수 있어요. 새 속성을 **추가**하는 건 괜찮아요. 깨졌다면 속성 이름을 원래대로 돌리면 고쳐져요.
</toggle>
