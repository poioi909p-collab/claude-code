# 잔향 殘響

관람객의 터치와 선이 작품이 되는 체험형 웹아트 전시.
Vite + TypeScript + Three.js(커스텀 GLSL) + GSAP + Web Audio API.

```bash
npm install
npm run dev        # http://localhost:5173 (같은 와이파이의 휴대폰에서도 접속 가능)
npm run build      # 타입 검사 + dist/ 생성
```

개발용 쿼리: `?room=1..4`로 해당 전시실에서 바로 시작, `?fps`로 프레임 표시, `?q=high|mid|low`로 품질 고정, `?fixed`로 자동 해상도 낮춤을 끕니다.

## 전시실

| | 방 | 상호작용 | 구현 |
|---|---|---|---|
| 0 | 입구 | 첫 터치 → 먹이 번지며 입장 | 명조 타이틀이 먹처럼 배어 나왔다가 풀어짐 |
| 1 | 먹 墨 | 누른 시간 = 농도, 빠른 획 = 갈필 | 나비에-스토크스 유체(핑퐁 FBO) + 한지 노이즈 셰이더. 젖은 먹은 섬유 방향으로 번지다 종이에 흡수되고, 마른 붓은 종이에 바로 갈라진 결을 남김. 마른 먹은 약 2분에 걸쳐 옅어짐(잔향) |
| 2 | 현 絃 | 선 긋기 → 실, 튕기기/가로지르기/잡아당기기 | 고정단 Verlet 사슬 위의 파동 방정식. 길이 → 계면조 펜타토닉 15음, 사인 + 약한 배음 + 생성형 임펄스 리버브. 튕긴 자리에 주홍 불꽃과 물결 |
| 3 | 흐름 流 | 손짓 → 결, 머무름 → 소용돌이, 기울기 → 중력 | 흐름장 텍스처에 손짓을 새기고 GPU 파티클 5만~10만 개(float 텍스처 핑퐁)가 따라 흐름. 장노출 트레일. iOS는 기울기 권한 버튼 표시 |
| 4 | 잔상 殘像 | 재생 → 서명 → PNG 저장 | 1~3실 스트로크를 시간순으로 압축해 한 장의 한지 위에 각 방의 어법(먹 · 실과 떨림의 겹선 · 빗질한 결)으로 다시 그림. 이름이 새겨진 주홍 낙관 + 날짜. 모바일은 공유 시트, 데스크톱은 다운로드 |

## 공통 시스템

- **입력** (`src/core/Input.ts`): Pointer Events로 마우스·터치·펜 통합. coalesced 이벤트와 이벤트 타임스탬프로 속도 측정. 매핑: 속도 → 굵기, 압력(펜) 또는 누른 시간 → 진하기, 방향 → 색온도(오른쪽 위로 따뜻하게, 왼쪽 아래로 차갑게). 두 손가락 가로 밀기로 전시실 이동.
- **기록** (`src/core/Recorder.ts`): 모든 스트로크를 타임스탬프와 함께 `Float32Array`로 보관(x, y, t, 굵기, 진하기, 색온도, 속도).
- **렌더러** (`src/core/Stage.ts`): WebGL 컨텍스트 하나를 모든 방이 공유. DPR 상한 2, 품질 단계 3개, 프레임이 계속 느리면 해상도 → 품질 단계 순으로 자동 하향.
- **합성** (`src/core/Compositor.ts`): 각 방은 오프스크린 타깃에 그리고, 최종 패스에서 먹이 스며드는 디졸브(먹이 번져 덮었다가 물러나며 다음 방이 드러남)와 필름 그레인, 비네트를 더함.
- **디자인**: 먹색 `#0B0B0C`, 미색 `#EDE8DF`, 주홍 `#D9481C` 세 가지 색만 사용. Noto Serif KR. 하단의 `01 / 04`, 소리 토글, 다음 화살표 외에 UI는 숨김. 넘김 힌트는 한 방에 16초쯤 머문 뒤에만 나타남.
- **접근성**: `prefers-reduced-motion`이면 전환은 짧은 크로스페이드로, 그레인은 정지, 소용돌이와 파티클 속도는 줄이고 잔상 재생은 짧게. 키보드: `→`/`←` 이동, `M` 소리, 입구에서 `Enter`.

## 성능 메모 (모바일 기준)

- 먹: 속도장 128², 염료 720(짧은 변), 야코비 16회. 붓 스플랫은 선분을 감싸는 작은 쿼드에만 가산 블렌딩으로 그림. 입력이 멈추고 7.5초가 지나면 유체 단계를 건너뜀.
- 현: 물리는 CPU(현 ≤ 14개 × 마디 ≤ 44개 × 12 서브스텝), 리본 지오메트리 하나로 그림. 잔상 버퍼는 화면의 1/2 해상도.
- 흐름: 파티클 65,536개(모바일), 트레일 0.75배 해상도. 파티클 밝기는 화면 면적과 점 크기로 정규화해 기기마다 밀도가 같게 보임. 모든 트레일 누적은 프레임률과 무관하게 맞춤.
- 잔상: 포스터는 2000×1500(모바일), 젖은 먹 확산은 절반 해상도에서 계산.
