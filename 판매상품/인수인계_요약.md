## 5. PRO 기능 정리

### 시트 구성
`사용법` / `대시보드` / `거래내역`(직접 입력 2,000행) / `통장붙여넣기`(3,000행) / `월별요약` / `월간리포트` / `손익·부가세` / `설정` + 숨김 시트 `_업종`, `_차트`

### 핵심 기능
1. **업종 선택 (설정!C9):** 8개 업종 중 하나를 고르면 아래가 한 번에 바뀜
   - 수입·지출 카테고리 (각 최대 15개)
   - 통장 자동 분류 규칙 (업종 기본 40~57개, 설정 L12:M71)
   - 과세유형, 간이 부가가치율, 상호명, 월 목표 매출 기본값
   - 고른 뒤에도 모든 노란 칸은 직접 고쳐 쓸 수 있음. 직접 추가 규칙 20개(L72:M91)가 업종 규칙보다 먼저 적용됨
2. **통장 붙여넣기:** 은행 엑셀을 제목 줄째로 B6에 붙여넣으면 자동으로 처리
   - 제목 줄 위치를 찾고, 날짜·시간·입금·출금·금액(한 열)·입출 구분·잔액 열을 인식함 (설정 O11:R21에 인식 결과와 직접 지정 칸)
   - 지원 양식: 출금이 먼저인 양식, 찾으신금액·맡기신금액, 금액 한 열(+/- 부호), 입출 구분 열, 제목 줄 없음
   - 날짜 형식: 2026.01.05 / 2026-01-05 / 2026/01/05 / 20260105 / 엑셀 날짜. 13월 같은 없는 날짜는 걸러냄
   - 중복: 잔액 열이 있으면 같은 거래를 자동으로 제외("중복 제외"), 없으면 "중복 의심"으로 표시
   - 맨 아래 '합계·총계·소계' 줄은 자동으로 빠짐
   - 분류: 내용 텍스트에서 키워드를 찾되, 입금이면 수입 카테고리, 출금이면 지출 카테고리만 고름 (LOOKUP 마지막 일치 방식이라 아래쪽 규칙이 우선). 못 찾으면 "미분류"(노란색)로 두고 '직접 고르기'에서 선택
3. **데이터 점검 (대시보드 Q6:S18):** 9개 항목을 점검함
   - 통장 미분류, 카테고리 불일치, 거래내역 입력 누락, 날짜 인식 실패, 금액 없는 행, 중복 의심, 중복 자동 제외, 다른 연도, 합계 행
   - 그리고 통장 열 인식 결과
4. **월간리포트:** 월을 고르면(C5) 아래가 나옴
   - 전월 대비 증감
   - 카테고리별 비중
   - 이번 달 지출 차트
   - 한 줄 요약 문장
5. **손익·부가세:**
   - 월별 손익분기 매출 (고정비 ÷ (1 − 변동비율))
   - 플랫폼 수수료율 (플랫폼 비용 ÷ 플랫폼 매출)
   - 부가세 예상 (일반: (매출 − 공제매입)/11 / 간이: 매출×부가가치율×10% − 공제매입×0.5%, 연 4,800만 미만이면 면제 / 면세: 0)
   - 간이과세에서 연 매출 1억 400만 원을 넘으면 경고
6. **수식 보호:** 입력 칸만 열어 두고 나머지는 시트 보호(암호 없음)
7. **호환:** 엑셀 2016 이상, 365, 맥용 엑셀. 구글시트에서도 계산은 되지만 일부 드롭다운은 엑셀에서만 보임

### LITE
- 업종 선택, 거래내역 직접 입력, 월별요약(매출·지출·순이익·이익률, 카테고리별 합계)만 있음
- 예시 데이터 1~3월이 들어 있음

## 6. 업종 프리셋 요약

| 업종 | 과세 기본값 | 간이율 | 대표 카테고리 / 규칙 예 |
|---|---|---|---|
| 음식점(배달·홀) | 일반 | 15% | 배민·쿠팡이츠·요기요·땡겨요, 식자재, 배달대행비 (우아한형제들→배민, 바로고→배달대행비) |
| 카페·베이커리 | 간이 | 15% | 원재료(원두·우유), 포장·소모품, 장비·수리 |
| 소매·동네가게 | 일반 | 15% | 상품매입(도매·유통·상사), 간편결제(제로페이 등), 포스·보안·관리 |
| 온라인 쇼핑몰 | 일반 | 15% | 스마트스토어(네이버파이낸셜), 쿠팡, 오픈마켓, 자사몰(PG), 택배비, 마켓수수료 |
| 미용·뷰티 | 간이 | 30% | 네이버예약, 재료·제품, 소모품·세탁, 제품판매 |
| 학원·교습소 | 면세 | - | 수강료(카드/계좌), 강사·직원 급여, 교재·교구, 차량운영 |
| 프리랜서·1인 서비스 | 간이 | 30% | 프로젝트 대금(용역), 플랫폼 정산(크몽·숨고), 장비·소프트웨어, 공유오피스 |
| 기타 서비스업 | 간이 | 30% | 계좌이체 매출, 예약플랫폼, 재료·부품, 장비·수리 |

- 공통 규칙: 카드사 9곳 → 카드매출, 급여·4대보험 → 인건비, 월세·관리비 → 임대료, 한전·가스·수도·통신 → 공과금, 광고·네이버·카카오 → 광고비, 세무서·국세 → 세금, 기장료 → 기타지출, 본인이체·내계좌 → 제외
- 예시 데이터의 연 이익률: 음식점 19%, 카페 19%, 소매 15%, 쇼핑몰 8%, 미용 22%, 학원 26%, 프리랜서 57%, 기타 23%

## 7. 검증 (마지막 실행: 모두 통과)

**은행 양식 10가지 상황** (매출·지출 합계가 원 단위까지 일치하고 오류 셀 0개)

| # | 상황 |
|---|---|
| A | 제목 줄 위 2줄 + 출금 먼저 + 숫자가 텍스트(콤마) |
| B | 찾으신·맡기신금액, 날짜와 시간이 다른 열 |
| C | 금액 한 열 + 부호 |
| D | 입출 구분 열 + 8자리 날짜 |
| E | 제목 줄 없음 |
| F | 기간 겹쳐 두 번 붙여넣기 + 합계 줄 |
| G | 잔액 없이 중복 (중복 의심 30건으로 표시) |
| H | 작년 내역 + 없는 날짜 |
| I | 빈 파일 |
| J | 2,990건 대용량 |

**업종 8가지**
- 예시 파일: 미분류·오분류·오류 0건, 데이터 점검 모두 ✓
- LITE: 오류 없음
- 빈 양식에서 업종만 바꿨을 때 카테고리·규칙·과세유형 전환 확인

**사용자 실수 상황**
- 카테고리 이름 변경 → '카테고리 불일치'로 경고됨
- 구분 누락 → '입력 누락'으로 경고됨
