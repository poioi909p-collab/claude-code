## ① 크몽 서비스 — 엑셀·구글시트 자동화

**카테고리:** IT·프로그래밍 > 업무 자동화 (또는 문서·글쓰기 > 엑셀)
**썸네일:** 썸네일_엑셀자동화.png

**제목**
엑셀 구글시트 수식, 자동화, 대시보드 빠르게 만들어 드립니다

**서비스 설명**
매일 반복하는 엑셀 작업, 손으로 하고 계신가요?
원하시는 결과만 말씀해 주시면 수식, 자동 집계, 대시보드까지 만들어 드립니다.

✔ 이런 분께 추천해요
- 매출·재고·거래처 데이터를 매번 손으로 정리하시는 분
- VLOOKUP, SUMIFS, 피벗 테이블이 막히는 분
- 여러 시트·파일을 하나로 합쳐야 하는 분
- 사장님 보고용 월별 요약표나 차트가 필요하신 분

✔ 작업 가능 범위
- 수식 작성 및 오류 수정 (VLOOKUP, INDEX/MATCH, SUMIFS, IF 중첩 등)
- 자동 집계표, 월별·카테고리별 요약
- 드롭다운, 조건부 서식, 입력 오류 방지
- 차트와 대시보드
- 구글 스프레드시트 함수 (QUERY, IMPORTRANGE, ARRAYFORMULA)
- 간단한 매크로(VBA)와 Apps Script

✔ 진행 방식
1. 원본 파일(민감한 정보는 지운 상태) + 원하는 결과를 보내주세요
2. 견적과 작업 시간을 안내해 드립니다
3. 작업 후 완성 파일과 사용법을 전달해 드립니다
4. 패키지별 횟수 안에서 무료로 수정해 드립니다

**패키지**
| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 가격 | 15,000원 | 30,000원 | 50,000원 |
| 내용 | 수식 1~3개 작성·수정 | 시트 1개 자동화 (집계표, 드롭다운, 서식) | 다중 시트 자동화 + 대시보드·차트 |
| 작업일 | 1일 | 2일 | 3일 |
| 수정 | 1회 | 2회 | 3회 |

**FAQ**
- Q. 파일에 개인정보가 있어요. → 이름이나 번호는 지우거나 가짜 값으로 바꿔서 보내주셔도 작업할 수 있습니다.
- Q. 맥(Numbers)에서도 되나요? → 엑셀 파일 기준으로 작업합니다. 구글시트로 열어서 쓰셔도 됩니다.
- Q. 견적이 애매해요. → 메시지로 파일과 원하는 결과를 보내주시면 무료로 견적을 드립니다.

## ② 크몽 서비스 — 파이썬 업무 자동화

**카테고리:** IT·프로그래밍 > 업무 자동화 / 크롤링
**썸네일:** 썸네일_파이썬자동화.png

**제목**
파이썬으로 반복 업무 자동화 프로그램 만들어 드립니다

**서비스 설명**
매번 손으로 하던 컴퓨터 작업, 클릭 한 번으로 끝나게 만들어 드립니다.

✔ 작업 예시
- 수백 개 파일 이름 일괄 변경, 폴더 정리
- 여러 엑셀·CSV 파일 합치기, 변환하기, 필터링하기
- 공개된 웹페이지 정보를 엑셀로 수집하기 (사이트 이용약관을 지키는 범위에서)
- PDF 합치기·나누기, 텍스트 추출
- 정해진 양식의 문서와 보고서 자동 생성

✔ 드리는 것
- 실행 파일 또는 소스 코드
- 설치·실행 방법 안내서 (처음 쓰시는 분도 따라 할 수 있게)

**패키지**
| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 가격 | 20,000원 | 40,000원 | 70,000원 |
| 내용 | 단순 자동화 1개 (파일 정리·변환) | 데이터 처리·수집 + 엑셀 저장 | 복합 자동화 + 사용 안내 |
| 작업일 | 1일 | 2일 | 4일 |
| 수정 | 1회 | 2회 | 3회 |

**안내**
로그인이 필요한 사이트 수집, 매크로를 이용한 예매·티켓팅, 사이트 약관을 위반하는 작업은 하지 않습니다.

## ③ 디지털 상품 — 매출·지출 관리 장부 (엑셀 템플릿)

**판매처:** 크몽 템플릿/전자책 카테고리, 포스타입 등 파일 판매가 가능한 곳
**파일:** 매출지출_관리장부.xlsx
**썸네일:** 썸네일_매출장부템플릿.png

**제목**
[엑셀 템플릿] 입력만 하면 끝나는 매출·지출 관리 장부 (자동 손익 대시보드)

**가격:** 5,900원 (출시 할인 3,900원도 고려해 보세요)

**상품 설명**
가게 장부, 아직도 노트에 쓰세요?
날짜, 금액, 카테고리만 입력하면 월별 손익과 차트가 자동으로 만들어집니다.

✔ 구성 (시트 5개)
- 대시보드: 연 매출, 지출, 순이익, 이익률 + 월별 매출·지출 차트 + 지출 구성 차트
- 월별요약: 월별 매출, 지출, 순이익, 이익률 / 카테고리별 월 지출표
- 거래내역: 2,000행 입력, 수입·지출·카테고리·결제수단을 목록에서 선택
- 설정: 연도, 상호명, 카테고리를 자유롭게 변경
- 사용법: 4단계 가이드

✔ 특징
- 수입은 초록, 지출은 빨강으로 자동 색 구분
- 날짜·금액을 잘못 입력하면 경고
- 적자인 달은 빨간색으로 강조
- 구글 스프레드시트에서도 작동
- 예시 데이터 포함 (지우고 바로 사용)

✔ 이런 분께
1인 자영업자, 배달 매장, 스마트스토어 셀러, 프리랜서

※ 디지털 파일 특성상 다운로드 후에는 환불이 어렵습니다.
