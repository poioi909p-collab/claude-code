## ② PRO — 자영업 매출장부 (업종 선택형)

**구매자에게 줄 파일:** 2_PRO_유료/자영업매출장부_PRO_빈양식.xlsx + 2_PRO_유료/업종별_예시 폴더 (예시 8개)
**썸네일:** 2_PRO_유료/썸네일_PRO.png
**상세 이미지:** 상세페이지_1.png → _2.png → _3.png 순서로 넣기 (한 장짜리가 필요하면 상세페이지_전체.png)
**가격:** 12,900원 (출시 기념 8,900원)

**제목**
[엑셀] 자영업 매출장부 PRO - 업종 선택형, 통장 붙여넣기 자동 분류, 손익분기점, 부가세 예상

**설명**
사장님, 이번 달 진짜 남았나요?

카드사·배달앱·스마트스토어 정산이 따로 들어와서 합계를 모르겠고,
플랫폼 수수료가 한 달에 얼마나 나가는지 모르겠고,
부가세 신고 때마다 갑자기 큰돈이 나가서 놀라셨다면 이 장부를 써 보세요.

✔ 업종만 고르면 세팅 끝 (8개 업종)
음식점(배달·홀) / 카페·베이커리 / 소매·동네가게 / 온라인 쇼핑몰 / 미용·뷰티 / 학원·교습소 / 프리랜서·1인 서비스 / 기타 서비스업
업종을 고르면 수입·지출 카테고리, 통장 자동 분류 규칙, 과세유형(일반·간이·면세), 간이 부가가치율이 한 번에 바뀝니다.
고른 뒤에도 카테고리와 규칙은 자유롭게 고쳐 쓸 수 있습니다.

✔ 은행 엑셀을 그대로 붙여넣기
인터넷뱅킹에서 내려받은 거래내역을 제목 줄째로 붙여넣으면 날짜·입금·출금·잔액 열을 자동으로 찾습니다.
출금이 먼저 나오는 양식, '찾으신금액/맡기신금액' 양식, 금액이 한 열인 양식도 읽습니다.
기간이 겹치게 두 번 붙여넣어도 같은 거래는 한 번만 계산하고, 맨 아래 '합계' 줄은 자동으로 뺍니다.

✔ 자동 분류
카드사 정산금은 카드매출, '우아한형제들'은 배민, '네이버파이낸셜'은 스마트스토어, 'CJ대한통운'은 택배비, '한국전력'은 공과금.
업종별 기본 규칙 40~57개에 직접 규칙 20개를 더할 수 있고, 못 찾은 내역은 노란색으로 알려줍니다.

✔ 데이터 점검
미분류, 날짜 인식 실패, 중복 의심, 카테고리 오타, 입력 누락을 대시보드에서 9가지 항목으로 점검합니다. 모두 ✓이면 숫자를 믿어도 됩니다.

✔ 월간 리포트
월만 고르면 전월 대비 증감, 카테고리별 비중, 한 줄 요약이 A4 한 장으로 정리됩니다.

✔ 손익분기점 · 플랫폼 수수료율 · 부가세 예상(참고용)
한 달에 최소 얼마를 팔아야 하는지, 배민·스마트스토어·예약앱 같은 플랫폼에 몇 %를 떼이는지, 부가세를 얼마나 떼어 둬야 하는지 알려줍니다.
일반과세자, 간이과세자(업종별 부가가치율), 면세사업자(학원 등)에 맞게 계산합니다.

✔ 판매 전 검증
은행 양식 5종, 중복 붙여넣기, 잘못된 날짜, 빈 파일, 2,990건 대용량 등 10가지 상황과 8개 업종 예시 모두에서 매출·지출 합계가 원 단위까지 맞고 오류 셀이 없는 것을 확인했습니다.

✔ 구성
대시보드 / 거래내역(2,000행) / 통장붙여넣기(3,000행) / 월별요약 / 월간리포트 / 손익·부가세 / 설정 / 사용법
수식 칸은 실수로 지워지지 않게 잠가 두었습니다 (암호 없음).
제공 파일: 바로 쓰는 빈 양식 1개 + 업종별 예시 파일 8개

✔ 작동 환경
엑셀 2016 이상, 엑셀 365, 맥용 엑셀. 구글 스프레드시트에서도 계산은 작동합니다 (일부 드롭다운은 엑셀 전용).

✔ 먼저 무료 LITE 버전으로 써 보세요.

※ 한 파일에서는 한 가지 은행 양식만 자동 인식합니다. 통장이 여러 은행이면 열 순서를 맞춰 붙이거나 파일을 하나 더 쓰세요.
