원하시는 결과만 말씀해 주시면 수식, 자동 집계, 대시보드까지 만들어 드립니다.
포트폴리오의 음식점 매출장부(통장 내역 자동 분류, 손익분기점, 부가세 예상)를 직접 만들었습니다.

- 여러 시트·파일을 하나로 합쳐야 하는 분

✔ 작업 가능 범위

- 드롭다운, 조건부 서식, 입력 오류 방지
- 차트와 대시보드
- 구글 스프레드시트 함수 (QUERY, IMPORTRANGE, ARRAYFORMULA)
- 간단한 매크로(VBA)와 Apps Script

✔ 진행 방식
1. 원본 파일(민감한 정보는 지운 상태) + 원하는 결과를 보내주세요
2. 견적과 작업 시간을 안내해 드립니다
3. 작업 후 완성 파일과 사용법을 전달해 드립니다
