**설명**
사장님, 이번 달 진짜 남았나요?

배민 정산, 쿠팡이츠 정산, 카드 매출이 따로 들어와서 합계를 모르겠고,
배달은 팔수록 남는 게 없는 것 같은데 수수료가 얼마나 나가는지 모르겠고,
7월과 1월 부가세 고지서에 매번 놀라셨다면 이 장부를 써 보세요.

✔ 은행 엑셀을 그대로 붙여넣기
인터넷뱅킹에서 내려받은 거래내역을 제목 줄째로 붙여넣으면 날짜·입금·출금·잔액 열을 자동으로 찾습니다.
출금이 먼저 나오는 양식, '찾으신금액/맡기신금액' 양식, 금액이 한 열인 양식도 읽습니다.
기간이 겹치게 두 번 붙여넣어도 같은 거래는 한 번만 계산하고, 맨 아래 '합계' 줄은 자동으로 뺍니다.

✔ 자동 분류
'우아한형제들'은 배민, '바로고'는 배달대행비, '한국전력'은 공과금. 분류 규칙 60개를 직접 추가할 수 있고, 못 찾은 내역은 노란색으로 알려줍니다.

✔ 데이터 점검
미분류, 날짜 인식 실패, 중복 의심, 카테고리 오타, 입력 누락을 대시보드에서 9가지 항목으로 점검합니다. 모두 ✓이면 숫자를 믿어도 됩니다.

✔ 월간 리포트
월만 고르면 전월 대비 증감, 카테고리별 비중, 한 줄 요약이 A4 한 장으로 정리됩니다.

✔ 손익분기점 · 배달 수수료율 · 부가세 예상(참고용)
한 달에 최소 얼마를 팔아야 하는지, 배달 매출 중 몇 %가 수수료인지, 1기·2기 부가세를 얼마나 떼어 둬야 하는지 알려줍니다. 일반과세자와 간이과세자(음식점 부가가치율 15%) 모두 계산합니다.

✔ 판매 전 검증
은행 양식 5종, 중복 붙여넣기, 잘못된 날짜, 빈 파일, 2,990건 대용량 등 10가지 상황에서 매출·지출 합계가 원 단위까지 맞고 오류 셀이 없는 것을 확인했습니다.

✔ 구성
대시보드 / 거래내역(2,000행) / 통장붙여넣기(3,000행) / 월별요약 / 월간리포트 / 손익·부가세 / 설정 / 사용법
수식 칸은 실수로 지워지지 않게 잠가 두었습니다 (암호 없음).

✔ 작동 환경
엑셀 2016 이상, 엑셀 365, 맥용 엑셀. 구글 스프레드시트에서도 계산은 작동합니다 (일부 드롭다운은 엑셀 전용).

2. 견적과 작업 시간을 안내해 드립니다
3. 작업 후 완성 파일과 사용법을 전달해 드립니다
